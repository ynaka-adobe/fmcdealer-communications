## Learnings

**Analytics and Insights**
- Analytics and Insights load in the delayed phase (about 3 s after load) through `scripts/delayed.js` → `analytics.js` → `insights.js`.
- Without `?insights=1` the panel is a collapsed "Insights" tab bottom right: hover to peek, click to pin. `?insights=0` turns it off for the tab session.
- "Loads nothing" was a stale cached `delayed.js` in the user's normal Edge window. An InPrivate window showed it. Headless Chrome against the live URL showed the panel and hits. Fix: hard refresh.
- Verify with `?analytics-debug=1`, `fmcAnalytics.dump()`, `fmcAnalytics.lastHit`, and Workspace for the report suite.
- `initInsights` runs only if `initAnalytics` resolves. Consider decoupling so a failed analytics init doesn't hide the panel (not done).

**Debugging approach that worked**
- Load the live URL in headless Chrome (`--dump-dom`, `--screenshot`, `--enable-logging=stderr`) to see the real DOM, console and a screenshot. jsdom can't catch real-browser problems.

**Guest codes / `/auth/code`**
- `POST /auth/code` returns `502 Edge function error` because the codes sheet `https://main--fmcdealer-communications--ynaka-adobe.aem.page/internal/access-codes.json` returns 404 (not created or not previewed in DA). `loadCodes` in `src/guest.js` throws and `redeemCode` doesn't catch it.
- A GET to `/auth/code` returns 405, which is expected (POST only).
- Fixes (not applied): create and preview the sheet in DA (`code`, `customer`, `expires` columns), and/or catch the error in `redeemCode` and redirect to `/access?error=unavailable`.
- The site's pages are anonymous. The code dialog was removed earlier.
